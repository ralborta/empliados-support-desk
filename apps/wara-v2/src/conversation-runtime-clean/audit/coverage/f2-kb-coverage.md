# F2 — cobertura KB → casos

| KB | Caso | Cobertura actual |
|---|---|---|
| KB-DOMAIN / KB-PLATFORM | `flow:kb-lateral-resume`, `capability:domain.answer` | contrato y XOR con GPS |
| KB-V1-OPCIONES / KB-V1-UNIDADES | `flow:kb-lateral-resume` | topic/facts; texto no copiado |
| KB-V1-MANTENIMIENTO | `flow:maintenance` | procedimiento asociado al trámite |
| KB-ODOO-LABELS | `flow:ticket-lifecycle` | status/ref tipados |
| PDFs Opciones/Unidades | pendiente extracción aprobada | inventariado, no incorporado |
| Knowledge DB/tenant files | pendiente repository real | inventariado, no incorporado |
| Prompt/templates/style | Composer futuro | no tratados como facts |
| datasets/traces/patches | runner LLM preparado | no tratados como KB |

El corpus no afirma cobertura de contenido no extraído o no accesible sin persistencia. Ver G para integraciones faltantes.
